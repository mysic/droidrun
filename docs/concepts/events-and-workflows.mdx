## Overview

Droidrun provides **real-time event streaming** that gives you visibility into agent execution as it happens. This allows you to build UIs, logging systems, or monitoring tools that react to agent actions in real-time.

Under the hood, Droidrun uses [llama-index workflows](https://docs.llamaindex.ai/en/stable/understanding/workflows/) - an event-driven orchestration system that powers the agent architecture.


## 基本用法

```python
from droidrun.agent.droid import DroidAgent

# 创建并运行 Agent
agent = DroidAgent(goal="Open Gmail and check inbox", config=config)
handler = agent.run()

# 实时流式接收事件
async for event in handler.stream_events():
    if isinstance(event, ManagerPlanDetailsEvent):
        print(f"📋 计划: {event.plan}")
        print(f"🎯 当前子目标: {event.subgoal}")

    elif isinstance(event, ExecutorActionEvent):
        print(f"⚡ 动作: {event.description}")
        print(f"💭 思考: {event.thought}")

    elif isinstance(event, ScreenshotEvent):
        save_screenshot(event.screenshot, "screenshot.png")

    elif isinstance(event, FastAgentResponseEvent):
        if event.code:
            print(f"🔧 工具调用: {event.code}")
        if event.thought:
            print(f"💭 思考: {event.thought}")

# 等待最终结果
result = await handler
print(f"✅ 成功: {result.success}")
print(f"📝 原因: {result.reason}")
```

## 常见模式

### 构建实时 UI

```python
async def run_with_ui(goal: str):
    agent = DroidAgent(goal=goal, config=config)
    handler = agent.run()

    async for event in handler.stream_events():
        if isinstance(event, ManagerPlanDetailsEvent):
            ui.update_plan(event.plan)
            ui.update_current_step(event.subgoal)

        elif isinstance(event, ExecutorActionEvent):
            ui.add_action_log(event.description, event.thought)

        elif isinstance(event, ScreenshotEvent):
            ui.update_screenshot(event.screenshot)

    result = await handler
    ui.show_completion(result.success, result.reason)
```

### 跟踪 Token 使用量

```python
async def track_token_usage(goal: str):
    agent = DroidAgent(goal=goal, config=config)
    handler = agent.run()

    total_tokens = 0
    total_requests = 0

    async for event in handler.stream_events():
        # 检查包含使用量信息的事件
        if hasattr(event, 'usage') and event.usage:
            total_tokens += event.usage.total_tokens
            total_requests += event.usage.requests

            print(f"LLM 调用 - 输入: {event.usage.request_tokens}, "
                  f"输出: {event.usage.response_tokens}, "
                  f"总计: {event.usage.total_tokens}")

    result = await handler
    print(f"\n📊 总共使用的 Token: {total_tokens}")
    print(f"📊 总 LLM 请求数: {total_requests}")
```

### 日志与监控

```python
import logging

logger = logging.getLogger("droidrun.monitor")

async def monitor_execution(goal: str):
    agent = DroidAgent(goal=goal, config=config)
    handler = agent.run()

    start_time = time.time()
    action_count = 0

    async for event in handler.stream_events():
        if isinstance(event, ExecutorActionEvent):
            action_count += 1
            logger.info(f"动作 {action_count}: {event.description}")

        elif isinstance(event, FastAgentOutputEvent):
            logger.info(f"工具执行结果: {event.output}")

    result = await handler
    duration = time.time() - start_time

    logger.info(f"任务在 {duration:.2f}s 内完成，共 {action_count} 次动作")
    logger.info(f"结果: {result.success} - {result.reason}")
```

## 说明

### 事件流行为

- 事件会在 Agent 执行时**实时流式**发送
- 并非每次执行都会发出所有事件（取决于模式与动作）
- 所有事件均为 **Pydantic 模型**，具有完整类型保障
- `handler` 对象是 **异步** 的 —— 请始终使用 `await handler` 获取最终结果

### 不同模式下的事件发出

**推理模式**（`reasoning=True`）会发出：
- 协调事件：`ManagerInputEvent`, `ManagerPlanEvent`, `ExecutorInputEvent`, `ExecutorResultEvent`
- Manager 内部：`ManagerContextEvent`, `ManagerResponseEvent`, `ManagerPlanDetailsEvent`
- Executor 内部：`ExecutorContextEvent`, `ExecutorResponseEvent`, `ExecutorActionEvent`, `ExecutorActionResultEvent`
- 工具执行：`ToolExecutionEvent`（每次工具调度后）
- 可视化：`ScreenshotEvent`, `RecordUIStateEvent`（启用时）

**直连模式**（`reasoning=False`）会发出：
- 协调事件：`FastAgentExecuteEvent`, `FastAgentResultEvent`
- FastAgent 内部：`FastAgentInputEvent`, `FastAgentResponseEvent`, `FastAgentToolCallEvent`, `FastAgentOutputEvent`, `FastAgentEndEvent`
- 工具执行：`ToolExecutionEvent`（每次工具调度后）
- 可视化：`ScreenshotEvent`, `RecordUIStateEvent`（启用时）

**所有模式**均会发出：
- 终结事件：`FinalizeEvent`, `ResultEvent`
- 遥测：`DroidAgentInitEvent`, `PackageVisitEvent`, `DroidAgentFinalizeEvent`（启用遥测时）

### 事件类别

**协调事件** - 用于 Agent 间的工作流路由（仅包含最小数据）
- 位于 `droidrun/agent/droid/events.py`
- 示例：`ManagerPlanEvent`, `ExecutorResultEvent`, `ExternalUserMessageAppliedEvent`

**内部事件** - 用于前端/日志流式传输（包含完整调试数据）
- 位于各 Agent 的事件文件中
- 示例：`ManagerPlanDetailsEvent`, `ExecutorActionEvent`, `FastAgentResponseEvent`

**通用事件** - 执行期间发出（用于截图、UI 状态记录和工具跟踪）
- 位于 `droidrun/agent/common/events.py`
- 示例：`ScreenshotEvent`, `RecordUIStateEvent`, `ToolExecutionEvent`

**遥测事件** - 用于分析收集（启用时）
- 位于 `droidrun/telemetry/events.py`
- 示例：`DroidAgentInitEvent`, `PackageVisitEvent`, `DroidAgentFinalizeEvent`
