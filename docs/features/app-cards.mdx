## 什么是 App 卡片？

App 卡片是针对特定应用的**操作指南**，用于教会 Agent 如何更有效地使用应用。把它们看作是为 Agent 准备的备忘单，帮助 Agent 理解：

- 如何在应用中导航界面
- 在何处查找按钮与功能
- 应用特有的快捷方式与手势
- 搜索语法和过滤器（例如 Gmail 的搜索）
- 常见工作流与最佳实践

**示例：** 当 Agent 打开 Gmail 时，会自动加载 Gmail 的 App 卡片，并学到：
- 撰写按钮位于右下角
- 搜索支持 `from:sender@email.com` 或 `has:attachment` 等过滤语法
- 向右滑动归档邮件，向左滑动删除邮件

这些知识能帮助 Agent 更快速且更可靠地完成任务。

---

## 为什么要使用 App 卡片？

**没有 App 卡片时：**
- Agent 需要猜测如何在不熟悉的应用中导航
- 反复试错会浪费时间与 Token
- 复杂流程的成功率降低

**使用 App 卡片时：**
- ✅ Agent 能准确定位功能位置
- ✅ 常见任务通常一次成功
- ✅ 减少 Token 消耗（减少探索）
- ✅ 更好地处理应用特有的奇性或例外情况

## 快速开始

项目自带一个 Gmail 示例 App 卡片，用于演示 App 卡片的工作方式：

```bash
# 默认启用 App 卡片
droidrun run "Send an email to john@example.com" --reasoning
```

当 Agent 打开 Gmail 时，Gmail 的 App 卡片会自动加载并引导工作流。

**示例卡片（包含）：**
- **Gmail** (`com.google.android.gm`) - 邮件导航、搜索、撰写

你可以将其作为模板为其他应用创建卡片（参见下文“创建自定义 App 卡片”）。

## App 卡片的工作原理

### 自动加载

1. **检测：** Agent 检测到前台应用（例如 Gmail）
2. **加载：** Droidrun 为该包名加载对应的 App 卡片
3. **注入：** 将 App 卡片内容加入到 Agent 的提示中
4. **引导：** Agent 使用这些指引做出更优决策

**技术说明：** App 卡片异步加载并缓存于内存，加载在后台进行，不会阻塞 Agent 执行。

### 何时使用？

App 卡片在推理模式下由 **Manager Agent** 使用（通过 `--reasoning` 标志或配置中的 `reasoning: true`）：

```bash
# 启用 App 卡片（Manager 在规划时使用）
droidrun run "Archive all unread emails" --reasoning

# 直连执行模式下不使用 App 卡片
droidrun run "Tap the button"
```

## 创建自定义 App 卡片

想为你常用的应用添加 App 卡片？按以下步骤操作：

### 步骤 1：查找包名

```bash
# 列出所有安装的包
adb shell pm list packages

# 或者筛选查找特定应用
adb shell pm list packages | grep keyword
```

**常见包名示例：**
- Chrome: `com.android.chrome`
- WhatsApp: `com.whatsapp`
- Instagram: `com.instagram.android`
- YouTube: `com.google.android.youtube`

### 步骤 2：创建文件

创建 App 卡片目录与文件：

```bash
mkdir -p config/app_cards
touch config/app_cards/app_cards.json
touch config/app_cards/chrome.md
```

**示例结构：**

```markdown
# Chrome App Guide

## Navigation
- Address bar at the top for entering URLs
- Three-dot menu (top-right) for settings and history
- Tabs button (top-right) to switch between tabs

## Search
- Type queries directly in the address bar
- Use voice search via the microphone icon

## Common Actions
- **New Tab**: Tap the tabs button → Plus icon
- **Close Tab**: Swipe tab away in tab switcher
- **Refresh**: Pull down from the top of the page
- **Bookmarks**: Three-dot menu → Bookmarks

## Tips
- Incognito mode available via three-dot menu
- Downloads accessible via three-dot menu → Downloads
```

### 步骤 3：注册 App 卡片

在 `config/app_cards/app_cards.json` 中添加映射：

```json
{
  "com.google.android.gm": "gmail.md",
  "com.android.chrome": "chrome.md"
}
```

**使用子目录示例：**

```json
{
  "com.whatsapp": "social/whatsapp.md",
  "com.instagram.android": "social/instagram.md"
}
```

### 步骤 4：测试

```bash
droidrun run "Open Chrome and search for droidrun" --reasoning --debug
```

查看日志信息：
```
Loaded app card for com.android.chrome from config/app_cards/chrome.md
```

## 配置

App 卡片默认启用，且从 `config/app_cards/` 加载：

```yaml
agent:
  app_cards:
    enabled: true
    app_cards_dir: config/app_cards
```

**若要禁用：**
```yaml
agent:
  app_cards:
    enabled: false
```

## App 卡片最佳实践

### 内容指南

**建议：**
- 言简意赅且可操作
- 侧重 UI 模式与工作流
- 包含搜索语法与特殊功能说明
- 提及常见坑与特殊行为
- 使用要点与清晰标题

**不建议：**
- 撰写长篇大论
- 详尽描述每一个功能点
- 包含频繁变动的信息（与版本相关的细节）
- 重复一般性的 Android 知识（Agent 已知如何点击、滑动等）

### 示例：好与坏对比

**❌ 不佳（过于冗长）：**
```markdown
Gmail is an email application developed by Google. It has many features
including the ability to send and receive emails. To compose an email,
you need to first understand that Gmail uses a material design interface
with a floating action button, which is a circular button...
```

**✅ 优秀（简洁且可执行）：**
```markdown
## Composing Emails
- Tap the floating compose button (bottom-right)
- Fill recipient, subject, and body
- Send via paper plane icon (top-right)
```

## 故障排查

### App 卡片未加载

**检查项：**

1. **包名是否正确？**
   ```bash
   adb shell dumpsys window windows | grep -E 'mCurrentFocus'
   ```

2. **app_cards.json 中的映射是否正确？**
   ```json
   {
     "com.your.app": "yourapp.md"
   }
   ```

3. **Markdown 文件是否存在？**
   ```bash
   ls config/app_cards/yourapp.md
   ```

4. **App 卡片功能是否启用？**
   ```yaml
   agent:
     app_cards:
       enabled: true
   ```

5. **是否在使用推理模式？**
   ```bash
   droidrun run "command" --reasoning
   ```

### 调试模式

使用 `--debug` 可查看 App 卡片加载情况：

```bash
droidrun run "Open Gmail" --reasoning --debug
```

查看日志输出：
```
Loaded app_cards.json with 2 entries
Loaded app card for com.google.android.gm from config/app_cards/gmail.md
```
